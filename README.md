# Мой PMP маршрут — версия 2.1

Учебный сайт для освоения управления проектами с опорой на опыт SAP и переносом в другие отрасли. Основное задание сохранено без изменений в [PRODUCT_SPEC.md](PRODUCT_SPEC.md).

## Открыть

Опубликованная версия: **https://rpkshnik-ops.github.io/pmp-study-hub/**.
Исходники: https://github.com/rpkshnik-ops/pmp-study-hub.

При переходе с localhost перенесите прогресс через экспорт и импорт в настройках: у нового адреса отдельное хранилище браузера.

Запустите из папки проекта:

```powershell
python serve.py
```

Откройте **http://localhost:8000**. Используйте тот же адрес и браузер, где уже учились: localhost и 127.0.0.1 имеют разные хранилища. Сервер доступен только с этого компьютера. Для запуска нужен Python 3.12+, сторонние пакеты не нужны.

При обновлении уже открытого приложения сохраните ответы и нажмите уведомление «Обновить», либо перезагрузите старую вкладку после установки обновления. Прогресс хранится отдельно от кеша приложения. Не очищайте данные сайта для обновления.

## Что есть

- **Маршрут → План на неделю**: конкретные задания, черновики, самопроверка и экспорт результатов. При нехватке времени одна тема занимает несколько недель.
- **Прогресс**: результаты по темам и доменам, слабые места и ссылки на нужное упражнение. Подсказки и знакомые ситуации учитываются отдельно.
- Поддержание закрепляет одну тему на неделю. Повторение предлагает пять карточек за день; дополнительная порция включается по желанию.

- 24 заново написанных урока: понятия, термины, разобранный пример, воспроизведение своими словами, новая ситуация, заполняемый рабочий документ и проверка.
- 120 оригинальных тематических вопросов: один/несколько ответов, числовой ввод, сопоставление через доступные с клавиатуры списки. 60 карточек повторения.
- 24 самостоятельных кейса и 24 заполняемых документа с рубриками. Ответы и черновики сохраняются автоматически; свои документы можно скачать.
- Практика с подробным разбором; короткая тренировка на время; история попыток; повторение 1/3/7/14/30 дней; журнал опыта и обучения.
- Экспорт, проверяемый импорт, объединение без дубликатов, резервная копия перед заменой, перенос старых сохранений.
- После первого успешного кеширования — уроки, практика и сохранение без сети.

Около 35 минут — ориентир для чтения **и самостоятельной работы**, а не обязательное время на странице. Для завершения нужны письменные ответы, документ, минимум три вопроса и самооценка. Приложение не оценивает смысл открытых ответов автоматически: сравните их с рубрикой и разбором.

Первый блок недельного плана можно завершить после понятий, примера и трёх ответов своими словами. Полное прохождение урока и вся недельная практика — отдельные отметки. Смена режима не удаляет черновики и историю.

## Проверки

```powershell
python verify.py
python verify.py --browser
```

Для проверок используются установленные Playwright для Python, Chrome и Node из комплекта Playwright. Пользователю для обычной работы они не нужны. Подробности и фактические результаты — [TESTING.md](TESTING.md).

После изменений ресурсов: `python tools/release.py --write`. GitHub Actions проверяет релиз и публикует только файлы приложения; инструкция по зависимостям — в TESTING.md.

## Данные и ограничения

Данные находятся в текущем браузере. Регулярно скачивайте экспорт в настройках. Автоматической синхронизации между компьютером и телефоном нет; перенос — через файл. Нынешний сервер принимает только локальные подключения.

AI в приложении выключен: уроки и объяснения не требуют API или платежей. Учебные материалы проверены моделями, без независимой экспертной сертификации. Статистика не обещает сдачу PMP или допуск.

Проверенного экзаменационного резерва — **0**. Полный пробник из 180 вопросов заблокирован; учебные 120 вопросов не объявлены независимым резервом. Это стартовый учебный набор, не исчерпывающий курс PMP. Точный объём реализованного и дальнейшая работа — [PROJECT_STATE.md](PROJECT_STATE.md).

[Аудит соответствия PMBOK 8 и PMP ECO 2026](CURRICULUM_AUDIT_2026-09-22.md) содержит карту всех 26 экзаменационных задач, оценку глубины уроков и план доработки. В частности, обнаружены подсказки длиной правильного ответа и шаблоном позиций; текущий банк нельзя считать независимой проверкой готовности. Метрики воспроизводятся командой `python -X utf8 tools/audit_coverage.py`.
