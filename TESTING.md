## Воспроизвести

Обычный запуск сайта не требует этих зависимостей. Для разработки:

```powershell
python -m pip install -r requirements-dev.txt
python -m playwright install chromium
python tools/release.py --write
python verify.py --browser
```

На Linux при необходимости: `python -m playwright install --with-deps chromium`. На Windows используется установленный Chrome, если найден; иначе Chromium Playwright. Переменная CHROME позволяет выбрать бинарный файл. Node берётся из PATH либо из комплекта Playwright.

## Что действительно проверяется

- Реальная миграция старого формата без schemaVersion: профиль, журнал и архив сохраняются; прежние оценки не повышают новые результаты.
- Глубокая проверка импорта, повреждённое сохранение, ошибка квоты, ограниченные резервные копии без рекурсивного вложения.
- Повторное объединение без дубликатов. Импорт заполняет пустые поля уже открытого урока, сохраняя заполненные текущие ответы.
- Четыре типа ответов, десятичная запятая, допуск числового результата, точный набор множественного выбора.
- Снимки вопросов в истории, выбор хронологически первой попытки после импорта, исключение подсказок и повторов из самостоятельной статистики.
- Непересекающиеся месяцы опыта, окно 120 месяцев, отсутствие автоматического учёта будущих дат и неподтверждённых записей.
- Подтверждённое завершённое обучение: некорректные и будущие даты не увеличивают часы.
- Интервалы карточек, абсолютный таймер, квоты 59/74/47 для 180 заданий, уникальные семейства и недостаточный резерв.
- 24 урока, 120 уникальных тематических вопросов, 60 карточек; все четыре типа; ссылки разрешаются через реестр; реальные метаданные model_reviewed.
- Контроль версии offline-кеша по хешу ресурсов: изменение кода или уроков требует нового release ID.

## Настоящие действия в Chrome/Chromium

Автоматический сценарий проходит onboarding и кнопку «Начать занятие»; заполняет самостоятельные ответы, проверяет скрытый разбор и скачивание документа; решает вопросы и завершает урок. Проверяет сохранение после reload, все четыре элемента ввода, экспорт/импорт/замену и отклонение повреждённого файла.

Дополнительно: сохранённые незавершённые тренировки после смены темы, блокировка импорта из устаревшей вкладки, таймер после reload, карточки, восстановление повреждённого сохранения, работа без сети, ширина 390 px без горизонтальной прокрутки, запрет публикации архива сервером. Отдельный одноразовый профиль проходит полное закрытие процесса браузера и перезапуск сервера.

Проверки не используют профиль настоящего ученика. На данной Windows установлен Kaspersky, который внедряет собственные сетевые запросы. Тест отдельно сообщает их и исключает только точный известный домен; внешних запросов приложения и AI-вызовов не обнаружено.
